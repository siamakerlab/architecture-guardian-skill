# Coding Style Template

## 1. General style
- 선호 문법/패턴
- 금지 패턴
- 코드 포맷팅 정책

## 2. OOP policy
- composition first
- constructor injection
- narrow public APIs
- immutable state for 핵심 객체

## 3. Naming conventions
- modules
- classes
- interfaces
- DTOs

## 4. Error handling
- 명시적 에러 경계
- 에러 타입 계약
- swallow policy

## 5. Side effects
- side effect 위치
- 순수 로직 구분

## 6. Testability rules
- DI 사용 위치
- 시간/랜덤/IO 분리

## 7. Documentation
- public API 문서
- 변경 사유 기록

## 8. Refactoring policy
- 작은 단위 우선
- 한 번에 한 책임 개선
